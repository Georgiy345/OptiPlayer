# OptiPlayer

**Быстрый и портативный видеоплеер для Windows с современным тёмным интерфейсом.**

![Windows 10/11](https://img.shields.io/badge/Windows-10%2F11-0078D4)
![Python 3.10+](https://img.shields.io/badge/Python-3.10%2B-3776AB)
![Qt 6.12](https://img.shields.io/badge/Qt-6.12-41CD52)

OptiPlayer открывает MP4 и другие видеоформаты, запоминает место просмотра, поддерживает плейлисты, субтитры, полноэкранный режим и мультимедиа-клавиши. Приложение не требует установки в систему: код, окружение, настройки и снимки хранятся в одной папке.

---

## Что это такое

OptiPlayer — это лёгкий плеер, который запускается без консоли и не пытается быть «комбайном». Его задача — быстро открыть видео, показать его красиво и не мешать.

Основной сценарий простой:

- перетащите видео в окно или нажмите **«Открыть файл»**;
- смотрите видео с плавающей панелью управления;
- при необходимости включите полный экран, плейлист, субтитры или смените скорость;
- закройте окно — позиция просмотра сохранится.

## Почему он такой

Хотелось получить плеер, который:

- **не тормозит** — видео декодируется аппаратно, а интерфейс не блокирует воспроизведение;
- **выглядит современно** — тёмная тема, скруглённое окно, аккуратные анимации и собственная панель управления;
- **не требует установки** — никаких инсталляторов, служб и мусора в системных папках;
- **работает с обычными файлами** — MP4, MKV, MOV, WEBM и другими форматами, которые поддерживает Qt FFmpeg.

### Почему Python, а не Java

Для видео важны аппаратное декодирование и быстрый кастомный интерфейс. **Python + PySide6 (Qt 6)** даёт готовую связку Qt Multimedia, FFmpeg и Qt Quick, а интерфейс рисуется нативно и остаётся отзывчивым. Java потребовала бы отдельный JDK/JavaFX и всё равно уступала бы по качеству видеоинтеграции на Windows.

Виртуальное окружение Python лежит в `.venv` рядом с приложением, поэтому глобальные пакеты системы не затрагиваются.

## Возможности

- **MP4 и другие форматы**: H.264/AAC работает гарантированно; H.265 и остальные кодеки — если их поддерживает Qt FFmpeg.
- **Аппаратное декодирование** через FFmpeg и Media Foundation (D3D11/DXVA).
- **Современный интерфейс**: тёмная тема, скруглённые углы, плавающая панель, автоскрытие управления.
- **Плейлист**: добавление файлов и папок, автопереход, повтор одного видео или всего списка.
- **Продолжение просмотра** с последней позиции с кнопкой «С начала».
- **Недавние файлы** на стартовом экране.
- **Субтитры**, встроенные в контейнер.
- **Скорость воспроизведения** от 0,25× до 2× и покадровое перемещение.
- **Масштаб видео**: вписать, заполнить или растянуть.
- **Снимок кадра** в PNG.
- **Полный экран без рамки и панели задач** — видео доходит до краёв экрана.
- **Мультимедиа-клавиши** и кнопка play/pause на мышке.
- **Запоминание настроек**: громкость, скорость, масштаб, повтор, размер и положение окна.
- **Защита от засыпания экрана** во время воспроизведения.

## Быстрый старт

### Если папка с программой уже готова

Запустите:

```powershell
.\OptiPlayer.vbs
```

Это тихий запуск без консольного окна. В готовой папке можно также использовать ярлык `OptiPlayer.lnk`, если он создан. Ярлык удобно скопировать на рабочий стол или закрепить на панели задач.

Также доступны:

| Файл | Назначение |
|---|---|
| `OptiPlayer.vbs` | обычный запуск без консоли; принимает путь к файлу |
| `OptiPlayer.cmd` | запуск из командной строки |
| `.venv\Scripts\pythonw.exe app.py` | прямой запуск через Python |

### Если вы скачали проект с GitHub

Нужны **Windows 10/11** и **Python 3.10+** (проверено на 3.13).

1. Скачайте репозиторий (**Code → Download ZIP**) или клонируйте его.
2. Откройте PowerShell в папке проекта и создайте окружение:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

3. Запустите `OptiPlayer.vbs` или `OptiPlayer.cmd`.

При желании создайте ярлык на `OptiPlayer.vbs` — иконка приложения лежит в `assets\optiplayer.ico`.

## Управление

Мышь:

- **один клик** по видео — пауза / воспроизведение;
- **двойной клик** — полный экран;
- **колесо** — громкость;
- **правый клик** — меню: скорость, масштаб, дорожки, снимок, информация о файле.

Клавиатура:

| Клавиши | Действие |
|---|---|
| `Пробел` | пауза / воспроизведение |
| `←` / `→` | −5 / +5 секунд |
| `Shift + ←` / `Shift + →` | −1 / +1 секунда |
| `Ctrl + ←` / `Ctrl + →` | −30 / +30 секунд |
| `↑` / `↓` | громкость |
| `M` | выключить / включить звук |
| `F` / `F11` | полный экран |
| `Esc` | выйти из полного экрана |
| `P` | показать / скрыть плейлист |
| `S` | снимок текущего кадра |
| `[` / `]` | скорость воспроизведения |
| `,` / `.` | покадрово назад / вперёд |
| `Page Up` / `Page Down` | предыдущее / следующее видео |
| `Home` / `End` | начало / конец видео |
| `0`–`9` | переход к 0–90 % видео |
| `V` | субтитры вкл / выкл |
| `Ctrl + O` | открыть файл |
| `Ctrl + Shift + O` | открыть папку |
| `?` / `F1` | справка по клавишам |

## Полный экран

В полноэкранном режиме окно становится безрамочным: убирается тонкая системная рамка и панель задач, поэтому видео занимает весь экран.

При переключении на другое приложение плеер перестаёт быть поверх всех окон, чтобы не мешать работе. Когда вы возвращаетесь в него, полный экран снова становится верхним. Это позволяет нормально пользоваться Alt+Tab.

---

## Мультимедиа-клавиши

Плеер понимает стандартные кнопки **play/pause**, **следующий**, **предыдущий** и **стоп**, в том числе кнопку на мышке.

Клавиши работают, когда видео воспроизводится или окно плеера активно. Так плеер не перехватывает кнопку у браузера или YouTube, если стоит на паузе в фоне.

Отключить обработку можно в контекстном меню видео: **«Медиаклавиши»**.

## Ассоциации видеофайлов

Windows запоминает программу **по расширению** (`.mp4`, `.mkv`, `.mov`…), а не по отдельному файлу.

1. Запустите один раз из папки проекта:

   ```powershell
   .\associate_video.cmd
   ```

   Скрипт добавит OptiPlayer в «Открыть с помощью», в «Приложения по умолчанию» и пункт **«Открыть в OptiPlayer»** в контекстное меню видеофайлов.

2. Назначьте плеер программой по умолчанию:

   - правый клик по видео → **Открыть с помощью** → **Выбрать другое приложение** → **OptiPlayer** → **Всегда использовать для .mp4**;
   - повторите для `.mkv`, `.mov` и других расширений;
   - либо откройте **Параметры → Приложения → Приложения по умолчанию → OptiPlayer** и отметьте все нужные типы сразу.

Для **отдельного файла** менять ассоциации не нужно: правый клик → **«Открыть в OptiPlayer»**. В Windows 11 этот пункт может находиться в **«Показать дополнительные параметры»**.

Windows не позволяет приложению незаметно менять ассоциации — последнее подтверждение всегда делает пользователь.

Если папка с программой будет перемещена, запустите `associate_video.cmd` заново. Отменить регистрацию:

```powershell
.\associate_video.cmd -Remove
```

## Где хранятся данные

Все пользовательские файлы лежат рядом с приложением:

```
OptiPlayer\
├─ app.py                  точка входа
├─ optiplayer\             исходный код
├─ .venv\                  виртуальное окружение Python
├─ assets\optiplayer.ico   иконка приложения
├─ data\settings.json      настройки, история, позиции просмотра
├─ data\optiplayer.log     журнал ошибок
├─ snapshots\              снимки кадров (PNG)
├─ OptiPlayer.vbs          тихий запуск
├─ OptiPlayer.cmd          запуск из консоли
├─ associate_video.cmd     регистрация ассоциаций
└─ associate_video.ps1     скрипт регистрации
```

Qt может держать небольшой кэш QML/шейдеров в `%LOCALAPPDATA%` — это системный кэш графических библиотек, а не установка приложения.

## Как это устроено

- **Python + PySide6 (Qt 6.12, LGPL)** — основа приложения.
- Видео выводится через QML `VideoOutput` внутри `QQuickWidget`. Это позволяет сохранить аппаратное декодирование и при этом рисовать панель управления, субтитры и стартовый экран обычными QWidget-оверлеями. Обычный `QVideoWidget` создаёт отдельный нативный слой, который перекрывает такой интерфейс.
- **Qt Multimedia** использует FFmpeg-бэкенд и Media Foundation для аппаратного H.264.
- Панель управления, плейлист, меню и диалоги написаны на QWidget и рисуются вручную — без внешних UI-библиотек.
- Настройки хранятся в JSON и записываются атомарно.
- Медиаклавиши обрабатываются через Windows-хоткеи, `WM_APPCOMMAND` и Qt-события — поэтому работают и кнопки на мышке.
- Полный экран использует DWM и верхний z-order окна; при потере фокуса верхний z-order снимается.

На тестовом файле **1920×1080, 60 fps, ~48 Мбит/с** плеер выдавал **60,3 кадра/с**, а задержка главного потока не превышала **24 мс**. Проверено на Windows 11 26H2.

## Ограничения

- Внешние файлы `.srt`/`.ass` пока не подключаются — поддерживаются только субтитры, встроенные в видео.
- Нет HDR-тонмаппинга, эквалайзера и видеофильтров.
- Набор кодеков зависит от Qt FFmpeg; MP4 (H.264/AAC) работает гарантированно.
- Приложение рассчитано на Windows; на других системах Windows-интеграция (полный экран, медиаклавиши) не работает.

## Удаление

1. Отмените регистрацию ассоциаций:

   ```powershell
   .\associate_video.cmd -Remove
   ```

2. Удалите папку с приложением и, если создавали, ярлык.

Приложение не требует установки. Записи об ассоциациях хранятся только в профиле пользователя (`HKCU`) и удаляются первым шагом.
