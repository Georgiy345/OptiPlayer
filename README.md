# OptiPlayer

Быстрый видеоплеер для Windows с современным тёмным интерфейсом. Основной формат — **MP4** (H.264 + AAC; H.265 — если его поддерживает система/Qt), но открываются и другие контейнеры, которые поддерживает Qt FFmpeg: MKV, WEBM, MOV, AVI, M4V и т. д.

Приложение целиком портативное: виртуальное окружение Python, настройки, история и снимки живут на диске **S:**. На диск C ничего не устанавливается.

### Почему Python, а не Java

Для задачи важны аппаратное декодирование видео и быстрый кастомный интерфейс. Связка **Python + PySide6 (Qt 6)** даёт готовый мультимедийный стек с FFmpeg/Media Foundation и Qt Quick для видео — при этом весь UI рисуется нативно и не тормозит. Java потребовала бы отдельный JDK/JavaFX и всё равно уступала бы по качеству видеоинтеграции на Windows. Окружение Python изолировано в `.venv` на S:, глобальные пакеты не затрагиваются.

---

## Возможности

- Плавное воспроизведение 1080p60 без задержек интерфейса (Qt FFmpeg + аппаратное декодирование Media Foundation).
- Современный интерфейс: тёмная тема, скруглённое окно, плавающая панель управления, плавные анимации.
- Перетаскивание файлов и папок прямо в окно.
- Плейлист с сохранением позиции в текущем видео, автопереходом и режимами повтора. `Ctrl` + перетаскивание добавляет файлы, не заменяя плейлист.
- Запоминание громкости, скорости, масштаба, положения окна и последней папки.
- Продолжение просмотра с места остановки (с кнопкой «С начала»).
- Снимки кадров в PNG.
- Встроенные субтитры MP4 (если дорожка есть в файле).
- Полноэкранный режим без рамки и панели задач — видео доходит до самых краёв экрана; «поверх всех окон», горячие клавиши.
- Автоскрытие панели управления во время просмотра и защита от засыпания экрана.
- Поддержка мультимедиа-клавиш (play/pause, следующий, предыдущий, стоп), в том числе кнопки на мыши; отключается в контекстном меню.

## Запуск

Основной способ:

```
S:\OptiPlayer\OptiPlayer.lnk
```

Можно скопировать ярлык на рабочий стол или закрепить на панели задач. Иконка уже встроена.

Другие варианты:

| Файл | Назначение |
|---|---|
| `OptiPlayer.vbs` | запуск без консольного окна, принимает путь к файлу |
| `OptiPlayer.cmd` | запуск из командной строки, тоже принимает путь |
| `S:\OptiPlayer\.venv\Scripts\pythonw.exe S:\OptiPlayer\app.py "D:\video.mp4"` | запуск напрямую |

Также можно просто перетащить видео в открытое окно или нажать «Открыть файл».

## Ассоциации видеофайлов

Windows запоминает программу **по расширению** (`.mp4`, `.mkv`, `.mov`…), а не по отдельному файлу. Один раз зарегистрируйте плеер:

1. Запустите **`S:\OptiPlayer\associate_video.cmd`** (от имени пользователя, права администратора не нужны).  
   Скрипт добавит OptiPlayer в список «Открыть с помощью», в «Приложения по умолчанию» и пункт **«Открыть в OptiPlayer»** в контекстное меню видеофайлов.
2. Назначьте его программой по умолчанию:
   - правый клик по видеофайлу → **Открыть с помощью** → **Выбрать другое приложение** → **OptiPlayer** → **Всегда использовать для .mp4**;
   - повторите для `.mkv`, `.mov` и других расширений;
   - либо откройте **Параметры → Приложения → Приложения по умолчанию → OptiPlayer** и отметьте все нужные типы сразу.

Для **отдельного файла** менять ассоциации не нужно: правый клик → **Открыть в OptiPlayer** (в Windows 11 пункт может находиться в «Показать дополнительные параметры»).

Windows не позволяет приложению незаметно менять ассоциации — последнее подтверждение всегда делает пользователь. Если папка `S:\OptiPlayer` будет перемещена, запустите `associate_video.cmd` заново, чтобы обновить пути. Отменить регистрацию можно командой:

```powershell
S:\OptiPlayer\associate_video.cmd -Remove
```

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Пробел` | пауза / воспроизведение |
| `←` / `→` | −5 / +5 секунд |
| `Shift + ←` / `Shift + →` | −1 / +1 секунда |
| `Ctrl + ←` / `Ctrl + →` | −30 / +30 секунд |
| `↑` / `↓` | громкость |
| `M` | выключить / включить звук |
| `F` или `F11` | полный экран |
| `Esc` | выйти из полного экрана |
| `P` | показать / скрыть плейлист |
| `S` | снимок текущего кадра |
| `[` / `]` | скорость воспроизведения |
| `,` / `.` | покадрово назад / вперёд |
| `Page Up` / `Page Down` | предыдущее / следующее видео |
| `Home` / `End` | начало / конец видео |
| `0`–`9` | переход к 0–90 % видео |
| `V` | субтитры вкл / выкл |
| `Ctrl + O` | открыть файл |
| `Ctrl + Shift + O` | открыть папку |
| `?` или `F1` | справка по клавишам |

Мышь: одиночный клик по видео — пауза/воспроизведение, двойной — полный экран, колесо — громкость. Правый клик открывает меню (скорость, масштаб, дорожки, снимок, информация о файле).

Мультимедиа-клавиши (включая кнопку play/pause на мышке) работают, когда видео воспроизводится или окно плеера активно. Полностью отключить их можно в контекстном меню видео («Медиаклавиши»).

## Где что лежит

```
S:\OptiPlayer\
├─ app.py                  точка входа
├─ optiplayer\             исходный код (Python + QML-видеоповерхность)
├─ .venv\                  виртуальное окружение Python (PySide6/Qt)
├─ assets\optiplayer.ico   иконка приложения
├─ data\settings.json      настройки, история, позиции просмотра
├─ data\optiplayer.log     журнал ошибок
├─ snapshots\              снимки кадров (PNG)
├─ OptiPlayer.lnk          ярлык для запуска
├─ OptiPlayer.vbs          тихий запуск
├─ OptiPlayer.cmd          запуск из консоли
├─ associate_video.cmd     регистрация ассоциаций видеофайлов
└─ associate_video.ps1     скрипт регистрации (вызывается из .cmd)
```

Qt может держать небольшой кэш QML/шейдеров в `%LOCALAPPDATA%` (доли мегабайта) — это системный кэш графических библиотек, а не установка приложения. Все пользовательские данные и окружение находятся на S:.

## Переустановка окружения

Если папка `.venv` была удалена или нужно обновить зависимости:

```powershell
cd S:\OptiPlayer
python -m venv .venv
S:\OptiPlayer\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Нужен установленный Python 3.10+ (проверено на 3.13). PySide6 ставится **внутрь** `.venv` на S:, глобальные пакеты на C не затрагиваются.

## Технические детали

- **Python 3.13 + PySide6 6.12 (Qt 6.12, LGPL)**.
- Видео выводится через QML `VideoOutput` внутри `QQuickWidget`: аппаратное декодирование сохраняется, а интерфейс рисуется обычными QWidget-оверлеями, поэтому панель, субтитры и стартовый экран не конфликтуют с видеослоем.
- Qt Multimedia использует FFmpeg-бэкенд и Media Foundation (D3D11/DXVA) для H.264.
- На тестовом файле 1920×1080, 60 fps, ~48 Мбит/с: 60.3 кадра/с, задержка главного потока не превышала 24 мс.
- Позиция просмотра сохраняется автоматически; при повторном открытии файла предлагается продолжить.
- Настройки записываются атомарно в `data\settings.json`.

### Ограничения

- Внешние файлы `.srt`/`.ass` пока не подключаются — поддерживаются только субтитры, встроенные в контейнер.
- Нет HDR-тонмаппинга, эквалайзера и видеофильтров.
- Формат и кодеки ограничены возможностями Qt FFmpeg; MP4 (H.264/AAC) работает гарантированно.

## Удаление

1. Если регистрировали ассоциации, выполните:

   ```powershell
   S:\OptiPlayer\associate_video.cmd -Remove
   ```

2. Удалите папку `S:\OptiPlayer` и, если создавали, ярлык на рабочем столе.

Приложение не требует установки и не пишет в системный раздел; записи об ассоциациях хранятся только в вашем профиле (`HKCU`) и удаляются первым шагом.
